# ar1vit0r-portfolio-next

Next.js/TypeScript/Tailwind rebuild of my personal portfolio site, built to demonstrate
React/TypeScript proficiency for job applications. Not yet deployed — the Three.js
boot/particle/portal scene (currently a plain `boot.js`/`scene.js` pair) still needs
porting to React Three Fiber before this replaces the live site.

## Development

```bash
npm run dev    # local preview
npm run build  # typecheck + lint + static export to out/
```
