# ar1vit0r-portfolio-next

Next.js/TypeScript/Tailwind rebuild of [ar1vit0r.github.io](https://github.com/ar1vit0r/ar1vit0r.github.io),
built to demonstrate React/TypeScript proficiency for job applications. Not yet deployed —
see `plan/` for the boot/particle/portal scene port (Plan B) still to come before this
replaces the live site.

## Development

```bash
npm run dev    # local preview
npm run build  # typecheck + lint + static export to out/
```
